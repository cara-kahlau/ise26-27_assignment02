# Einen Kaffee kaufen

## Statement
Wenn ein Nutzer einen Kaffee kauft, MUSS die Coffee Kitty den Preis für einen Kaffee vom Kontostand des Nutzers abziehen. 

## Rationale
Menschen trinken gerne Kaffee. Bisher wurden Käufe mit einer Strichliste verwaltet. Mit einer App ist das weniger Aufwand, und Nutzer sehen automatisch, wieviel Guthaben oder Schulden sie haben.
Annahme: Menschen können auf einen Button klicken.

## Success Criteria
- Ein gekaufter Kaffee setzt den Kontostand um den Kaffeepreis nach unten
